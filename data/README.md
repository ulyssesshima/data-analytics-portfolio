# Data layer



Datasets sintéticos para demonstrar visualização e manutenção de dashboards. Não representam clientes, empregadores ou operações reais.



## Arquivos



- `executive.json`: performance executiva agregada.
- 
- `supply.json`: cobertura, disponibilidade e perdas sintéticas.
- 
- `quality.json`: completude, validade, drift e confiança sintética.
- 


Use `FICTÍCIO` para demonstração, `REPORTADO` para métricas profissionais sem evidência pública e `VERIFICADO` apenas com fonte autorizada. Nunca inclua CPF, e-mails, telefones, credenciais, dados proprietários ou amostras protegidas por NDA.
